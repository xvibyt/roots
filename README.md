Project description:
  This is a cozy game with no concrete goal.
  Placing down roots, you can be creative and make unique shapes.
  The catch is that the roots cannot be placed in any way you would like. They have to be connected in a realistic way to each other. You also can't build up.

Controls:
  To select roots to place, you click on one of the two buttons at the little holographic display on top of the dead tree. After the click, you can now place the randomly selected root. Re-roll as many times you wish to, if the selected root doesn't fit for you.
  The depth-level is infinitely generated downwards, to get down you have to scroll.

I didn't have enough time to finish the game completely, so it has only very basic gameplay. The water and bone tiles you can see were supposed to be used for being able to place more roots, but that didn't make it before the deadline unfortunately.
I also created a lot of animated assets mostly for like animals, which would move on top of the grass, but I couldn't get their movement logic to work so I had to scrap them.

I didn't use any AI.
